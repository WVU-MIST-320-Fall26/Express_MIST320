Epic 1 — Patient Onboarding
Purpose: Allow patients to complete required paperwork and provide important information digitally before arriving at the clinic.
Roles: Patient
Issues:
1. Implement Digital Patient Forms
User Story: As a patient I want to complete my required forms online before my appointment to save time.
2. Build a Medical History Questionnaire
User Story: As a patient I want to provide my medical history before I get to the clinic.
3. Upload Patient Documents
User Story: As a patient I want to upload my documents like ID and insurance card so I don't have to wait for my information to be verified at the clinic.
4. Digital Consent Forms
User Story: As a patient I want to sign consent forms digitally so I don't have to fill out paperwork at the clinic.
5. Insurance Pre-Check
User Story: As a patient I want my insurance coverage to be checked automatically so I know if I'm covered before my visit.

Epic 2 — Appointment Scheduling
Purpose: Give patients the ability to schedule appointments and receive reminders, reducing missed appointments and calls to clinic staff.
Roles: Patient 
Issues:
6. Scheduling Interface
User Story: As a patient I want to schedule appointments online so there isn't a need to call the clinic.
7. Text/Email Reminders
User Story: As a patient I want to receive appointment reminders so that I don't forget about upcoming visits.
8. Auto fill waitlist system
User Story: As a patient I want to join a waitlist and automatically fill an appointment slot when one opens.

Epic 3 — Automated Patient Services
Purpose: Automate routine patient services to reduce workload and give patients faster access to assistance and billing information.
Role: Patient
Issues:
9. AI Call System
User Story: As a patient I want automated billing so that I can quickly view and pay my balances without having to contact the clinic.
10. Automated Billing
User Story: As a patient I want automated billing so I can quickly view and pay balances without contacting the clinic.
11. Automated Payment reminders
User Story: As a patient I want to be reminded to pay payments so I don't miss due dates.

Epic 4 — Patient Verification
Purpose: Ensure patient identity and insurance information can be verified before appointments while restricting sensitive information to authorized employees only.
Roles: Employee, Patient
Issues: 
12. Insurance and ID Verification
User Story: As an employee I want to verify patient identify and insurance information so that I can have accurate records before appointments.
13. Multi Step Identity Verification
User Story: As a patient I want multi step identity verification so that my account and personal information is secure.
14. Document expiration alerts
User Story: As a patient I want alerts when my ID or insurance documents need updated so they don't expire.

Epic 5 — Patient Profile & Security
Purpose: Provide patients with a secure account where they can access, manage, and update their personal information.
Role: Patient 
Issues:
15. Patient Management Page
User Story: As a patient I want to manage my personal information so that my profile stays accurate.
16. Authentication
User Story: As a patient I want a secure login options to keep my account and information protected
17. Patient Activity log
User Story: As a patient I want to view my account activity so I can monitor changes and see if anything has been messed with.
